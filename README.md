# 🦟 Painel Preditivo e Territorial de Vigilância Epidemiológica - Dengue (São Paulo)

**UNIVESP - Projeto Integrador IV (Ciência de Dados)**

## 📌 Descrição do Projeto
Aplicação web para análise e espacialização em escala de dados de saúde pública (Dengue/SUS) no Município de São Paulo, utilizando aprendizado de máquina (K-Means) para clusterização de risco territorial e busca por CEP/Região.

## 🛠️ Tecnologias
- Python / Flask
- Pandas / Scikit-Learn (K-Means)
- Leaflet.js / Tailwind CSS
- Ingestão via API de Dados Abertos do SUS
